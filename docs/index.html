Recorded evidence

Evaluation figures reproduce the repository's archived conch-retention-001 results on the CRC-VAL-HE-7K benchmark, not a fresh test on independent patients. The model's pretraining overlap is unknown.

02

No private data

There are no original slide images, model weights, credentials, collection exports, uploads, or private APIs in this preview. The image-like patterns are abstract illustrations only.

03

No compute bill

No neural network runs for visitors. Site hosting serves only static HTML, CSS, and JavaScript. The original research server can stay offline or password-protected.
