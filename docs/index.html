What works in this public version?

Image browsing and zoom, reference-label review, notes, evidence selection, local image import, appearance-based similarity, and JSON or illustrated HTML report export all run in your browser. Sample reviews and findings are saved in this browser when storage is available. Imported images stay in the current tab.

Optional MobileNet CPU inference runs locally after you enable it. Arbitrary text-to-image search, retraining, shared accounts, and server storage are not connected. Dataset reference labels are not predictions. The benchmark page contains separate archived model evaluation results.

Images: Kather, Halama & Marx, CRC-VAL-HE-7K, CC BY 4.0. First four filenames per class; TIFF converted to PNG. Download sample manifest.

Run a model on your CPU

Optional · TIA MobileNetV3-Small · Colorectal H&E tissue tiles

Downloads a 3.7 MB model and about 11.3 MB of runtime files on first use. Images stay on your device. Uses one CPU worker; speed and memory use depend on your device. This is a different model from the archived CONCH benchmark. On these 36 demo tiles it agrees with 23 reference labels; this small sample is not an independent performance estimate.
