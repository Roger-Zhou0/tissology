A recorded research workspace

This workspace makes the archived CONCH retention classifier evaluation explorable without running the model. It uses the same nine-class benchmark record published in the Tissology repository.

Dataset
CRC-VAL-HE-7K · 7,180 colorectal H&E tiles
Model
CONCH + retention-trained colorectal tissue classifier
Release
conch-retention-001
Evidence available
Class-level metrics and the full confusion matrix. Individual images and predictions are not included.

Reading the results

Recall measures the fraction of a reference class assigned the correct label. Precision measures the fraction of predictions for a class that agree with the reference. F1 balances the two. Macro F1 weights every class equally.

This is a reused benchmark, not fresh patient-level validation. Model pretraining overlap is unknown. Results do not establish performance on new collections, clinical diagnostic accuracy, tissue area, or cell counts.

Hosting and your work

GitHub Pages serves these static files. Filtering, calculations, and notes run in your browser. There is no model inference, account, upload, analytics, or connection to the original research server. Findings are held in memory until you close or reload the tab.
